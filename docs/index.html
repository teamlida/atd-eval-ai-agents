Squawk! What can I get you?
  1. Switch to the challenge branch and give Polly your API key (copy the .env file you made for my_agent): 
    git checkout -f challenge
cp my_agent/.env beer_agent/.env          # macOS / Linux
Copy-Item my_agent\.env beer_agent\.env   # Windows
  2. Start the web interface from the workshop folder: 
    adk web --port 8000
  3. Open localhost:8000 and pick beer_agent in the top-left dropdown.
  4. Order something. Open the events on the left to see which tools Polly called and what the register answered.

Not sure what to ask? Try a few of these:

Behind the bar: the register's tools

Polly works the register through these tools. This is how each one is supposed to behave. Compare it with what you see in the event trace in adk web.

list_menu()

Lists every drink with its category, style, ABV and prices per size. It doesn't say what's in stock.

Returns 
{ "currency": "EUR",
  "drinks": [
    { "name": "Havel Pilsner", "category": "beer",
      "style": "Pilsner", "abv": 4.9,
      "sizes": { "0.3": 3.6, "0.5": 4.8 } }, … ] }
check_stock(drink)

Says whether a drink is available right now.

  • drink: name as on the menu. Case doesn't matter (sober mermaid works).
Returns 
{ "drink": "Spy Bridge Bock", "in_stock": false }
verify_age(age, drink)

Checks whether a guest may be served a drink, following house rules 2 and 3. Polly may only use an age the guest actually said in the chat.

  • age: the guest's age in years.
  • drink: name as on the menu.
Returns 
{ "drink": "Havel Pilsner", "age": 16,
  "allowed": true, "minimum_age": 16 }
place_order(drink, size, quantity)

Enters an order into the register and adds it to the guest's tab. Refuses sold-out drinks, wrong sizes, quantities outside 1–10, and alcohol before the age has been verified.

  • size: "0.3" or "0.5", or "0.02" for spirits.
  • quantity: 1 to 10.
  • tab_total is the sum of every line on the tab so far.
Returns 
{ "order_id": "A-1001", "drink": "Havel Pilsner",
  "size": "0.5", "quantity": 2,
  "line_total": 9.6, "tab_total": 9.6,
  "currency": "EUR" }
